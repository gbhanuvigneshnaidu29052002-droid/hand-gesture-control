# Hand Gesture Controlled Mouse using Computer Vision

## Overview
This project implements a real-time hand gesture-based mouse control system using computer vision. It leverages MediaPipe for hand tracking and translates gestures into mouse movements and clicks.

## Features
- Real-time hand tracking
- Cursor movement using index finger
- Single click using index + middle finger
- Double click using index + middle + ring finger
- Smooth cursor control
- FPS display

## Tech Stack
- Python
- OpenCV
- MediaPipe
- NumPy
- PyAutoGUI
